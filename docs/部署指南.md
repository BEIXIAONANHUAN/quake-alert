# 地震预警 · 部署指南（傻瓜版）

> 面向非程序员。标注 **【你要做的】** 的步骤需要你亲手操作；其余都可由助手自动完成。

---

## 0. 你需要准备的账号

- GitHub 账号（已有）
- Supabase 账号（已有）
- 微信 + PushPlus 公众号（token 已配置）

---

## 1. 新建 Supabase 项目

**【你要做的】**

1. 打开 <https://supabase.com/dashboard>
2. 点 **New project**
3. Organization 选你的组织
4. Project name 填 `quake-alert`（或任意）
5. Database Password 设一个强密码并记下
6. Region 建议选 **Northeast Asia (Tokyo)**
7. 点 **Create new project**，等 1～2 分钟变成 Active

完成后在 **Project Settings → API** 里能看到：

- `Project URL`（形如 `https://xxxx.supabase.co`）
- `anon` `public` key
- `service_role` key

把这三样交给助手（service_role 只给助手配置用，不要发到公开仓库）。

---

## 2. 执行建表 SQL

**【你要做的】** 打开 Supabase 左侧 **SQL Editor**，把项目里的 `supabase/schema.sql` 全文粘贴进去，点 **Run**。

也可以让助手用 Access Token 自动执行。

成功后应看到 `settings`、`alerts` 两张表出现在 Table Editor。

---

## 3. 部署 Edge Function 并设置 Secrets

### 3.1 设置 Secrets（Supabase）

**【你要做的】** Dashboard → **Edge Functions** → **Secrets**（或 Project Settings → Edge Functions → Secrets），添加：

| Name | Value |
|---|---|
| `PUSHPLUS_TOKEN` | `bc1872ffda0a4f6c8265ca88bd3a419b` |
| `CRON_SECRET` | 自己想一串长随机字符（也可让助手生成） |

### 3.2 部署函数

三个函数目录：

- `supabase/functions/quake-monitor`
- `supabase/functions/nightly-report`
- `supabase/functions/test-push`

**【你要做的】（若助手无法直连）** 在本机安装 [Supabase CLI](https://supabase.com/docs/guides/cli) 后：

```bash
supabase login
supabase link --project-ref <你的项目ref>
supabase functions deploy quake-monitor
supabase functions deploy nightly-report
supabase functions deploy test-push
```

---

## 4. 创建 GitHub 仓库并上传

助手可自动：`git init` → 提交 → 创建远程仓库 → push。

**【你要做的】** 仅当需要浏览器授权 GitHub 时，按助手指引登录一次。

---

## 5. 开启 GitHub Pages

仓库 → **Settings → Pages**：

- Source: `Deploy from a branch`
- Branch: `main` / `(root)`
- Save

约 1 分钟后得到网址：`https://<用户名>.github.io/<仓库名>/`

---

## 6. 配置 GitHub Actions 密钥

仓库 → **Settings → Secrets and variables → Actions** → **New repository secret**：

| Name | Value |
|---|---|
| `SUPABASE_FUNCTION_BASE` | `https://<ref>.supabase.co/functions/v1` |
| `SUPABASE_SERVICE_ROLE_KEY` | 项目的 service_role key |
| `CRON_SECRET` | 与 Supabase Secrets 中相同的值 |

Actions 会：

- 每 5 分钟调用 `quake-monitor`
- 每天 UTC 15:00（日本 0 点）调用 `nightly-report`

---

## 7. 填写前端配置

把 `js/config.js` 中：

```js
SUPABASE_URL: "YOUR_SUPABASE_URL",
SUPABASE_ANON_KEY: "YOUR_SUPABASE_ANON_KEY",
```

改成你的 Project URL 与 anon key，然后推送。助手部署时会自动填好。

---

## 8. 开启邮箱登录（Supabase Auth）

**【你要做的】** Supabase → **Authentication → Providers → Email**：

- 确认 Email 已启用
- 可关闭「Confirm email」以便魔法链接更顺畅（个人自用推荐）
- **Authentication → URL Configuration**：
  - Site URL：你的 GitHub Pages 网址
  - Redirect URLs：加上同一网址

---

## 9. 手机安装 PWA

1. 手机浏览器打开网站并登录
2. **安卓 Chrome**：菜单 →「添加到主屏幕」
3. **iPhone Safari**：分享 →「添加到主屏幕」
4. 主屏出现「地震预警」图标，点开全屏使用

## 常见问题

**微信收不到推送？**  
打开 PushPlus 官网查看是否关注服务号、token 是否有效；点网站「发送测试推送」看返回。

**Actions 报 401？**  
检查 `SUPABASE_SERVICE_ROLE_KEY` 与 `CRON_SECRET` 是否和 Supabase 一致。

**地震来了没推送？**  
冬眠是否开启；震度是否低于下限；是否属于 EEW 且地区不含「山梨県」。
